# SonicStream - Premium DJ & Radio Platform Template

SonicStream is a high-performance, modern template designed for DJ management, live radio broadcasting, and interactive listener platforms. It features a stunning glassmorphic interface, dark/light mode, and full RTL support.

## 🚀 Key Features
- **Responsive Design**: Mobile-first approach for all screens.
- **Glassmorphism UI**: Premium visual aesthetics with blur effects.
- **Live Player Component**: Built-in sticky player for immersive listening.
- **DJ Dashboard**: Comprehensive portal for show stats, scheduling, and profile management.
- **Theme Support**: Seamless Dark/Light mode toggle.
- **Multi-language Ready**: Built-in RTL support for international audiences.

## 📁 Project Structure
- `assets/css/`: Style system (Main, Dark Mode, RTL).
- `assets/js/`: Core logic and dashboard interactivity.
- `pages/`: Template pages (Home, About, Services, Dashboard, etc.).
- `documentation/`: Integration guides and technical specifications.

## 🛠️ Technology Stack
- **HTML5**: Semantic and SEO-optimized markup.
- **CSS3**: Vanilla CSS with modern variables and flex/grid layout.
- **ES6+ JS**: Modular, performance-focused logic.
- **Lucide Icons**: Clean, scalable vector icons.
